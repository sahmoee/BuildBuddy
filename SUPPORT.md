# BuildBuddy Support

Email [support@sowensstudios.com](mailto:support@sowensstudios.com) with the BuildBuddy version, macOS version, the action that failed, and sanitized console output. Remove tokens, private repository URLs, source code, signing details, and credentials first.

Before requesting help, run **Doctor**, confirm command-line tools are installed, verify the selected project and scheme, and check Git/GitHub authentication directly. For Remote issues, disable Public mode, rotate the pairing token, and test on a trusted LAN.
