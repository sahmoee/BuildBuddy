BuildBuddy v1.9 faster git plus ten improvements and ten new features

BUILD FIX
Fixed two type errors in the favorite star color, where a Color and a hierarchical style were
mixed in the same conditional. Both now use an explicit Color so the build succeeds.

PERFORMANCE
Git commands no longer launch a login shell, which used to re-read the entire shell profile
on every call. They now use a non login shell with a pre resolved PATH. Project status reads
in a single batched git command and is cached per project, so reselecting a project paints
instantly.

TEN IMPROVEMENTS
Refresh all projects at once, ahead and behind versus origin shown in the header, a Fetch
button, Stash and Unstash, Discard changes with a confirmation, Copy current commit SHA, Open
on GitHub, a per action busy label that shows what is running, guarding against overlapping
actions, and a one click helper to grant folder access.

TEN NEW FEATURES
A project search box, a multi project dashboard, a built in diff viewer for pending changes,
recent commit history, a command palette on command K, favorite or pinned projects, per
project notes, commit all dirty repositories at once, a quick branch switcher, and a menu bar
quick actions extra.

NOTE
Because this drop replaces the app source, relaunch BuildBuddy after applying, or use Check
for Updates once you are on a version that has it.

FILES CHANGED
BuildBuddy.swift, Launch BuildBuddy.command, and CHANGELOG.md.
