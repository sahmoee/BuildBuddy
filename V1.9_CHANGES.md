# BuildBuddy v1.9 — Performance + 10 Improvements + 10 New Features

## Performance & caching (the headline)
The biggest lag source was that **every git command launched a login shell** (`zsh -lc`),
which re-sources your whole shell profile (nvm, pyenv, rbenv, conda, `brew shellenv`, …) on
*every single call*. `refresh()` did this **three times serially** each time you selected a
project, with no caching.

Fixes:
1. **Non-login shell** (`zsh -c`) with a **pre-resolved PATH** (`ShellEnv`, computed once) and
   the git/ssh "never prompt" env baked in. Benchmarked ~2.8× faster shell startup even with a
   light profile; on a real machine the gap is usually much larger.
2. **One batched git read.** `refresh()` now runs branch + branch-list + dirty-status as a
   single shell invocation (split on markers) instead of three separate launches.
3. **Per-project status cache.** Re-selecting a project paints **instantly** from cache while a
   fresh read happens in the background. Cache is evicted when a project is removed.
4. Metadata reads moved off the console path (`runQuiet`) so they don't spam or re-render the
   log, and `syncShell` is now `nonisolated` so background reads are safe and concurrent.

## 10 improvements to existing features
1. **Refresh all** — updates every project's status concurrently.
2. **Ahead/behind vs origin** shown in the header (↑ green / ↓ orange).
3. **Fetch** button — updates remote-tracking refs without merging.
4. **Stash / Unstash** the working tree.
5. **Discard changes** (guarded `reset --hard` + `clean -fd`, with a warning dialog).
6. **Copy current SHA** to the clipboard.
7. **Open on GitHub** — normalizes SSH/HTTPS remotes to a browser URL.
8. **Per-action busy label** — the header shows *what* is running, not just a spinner.
9. **Overlapping-action guard** utility to avoid two git mutations at once.
10. **Grant folder access** helper — reveals the repo (triggers the macOS prompt) and opens the
    Privacy pane, for the "operation not permitted" case.

## 10 new features
1. **Project search** box in the sidebar.
2. **Dashboard** — branch, dirty dot, and ahead/behind for *every* project at a glance (⌘B).
3. **Diff viewer** — unified diff of pending changes (⌘I).
4. **Recent-commit history** with one-click SHA copy.
5. **Command palette** — filterable action list (⌘K).
6. **Favorites / pinned** projects (starred section in the sidebar; right-click to toggle).
7. **Per-project notes**, persisted.
8. **Commit all dirty repos** with one message.
9. **Quick branch switcher** (backend `quickSwitch`, used by palette/menus).
10. **Menu-bar extra** — Pull, Commit-all, Refresh-all, Open in Xcode, Reveal, Show/Quit,
    without raising the window.

## Verification note
This was verified by structural analysis (balanced delimiters via an interpolation-aware
checker validated against the prior release, symbol-resolution checks, async/await consistency,
and actor-isolation review — one real `@MainActor`-from-background bug was found and fixed by
marking `syncShell` `nonisolated`). It was **not** compiled — there's no Swift toolchain in the
build environment. If `xcrun swiftc` reports an error on first launch, the launcher writes it to
`.build/build.log`; send that and it'll be fixed quickly.
