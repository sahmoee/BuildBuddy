## Description

Your Apple development workflow, in one place.

BuildBuddy turns repetitive project chores into clear, reviewable actions. Add local repositories, understand their state, build Apple targets, manage Git history, apply deliveries, and deploy supported services without rebuilding the same command sequence every day.

SEE WHAT CHANGED
Review status, branches, history, ahead/behind state, and colorized diffs before you act. Copy commit identifiers, stash work, fetch updates, and move between projects quickly.

BUILD WITH CONFIDENCE
Run configured Xcode schemes, inspect results, bump versions, open the right project, and use Doctor to catch common environment problems.

CONTROL DELIVERY
Apply reviewed delivery archives, create traceable commits, push to configured remotes, and deploy supported sites or Workers using the tools already installed on your Mac.

OPTIONAL REMOTE ACCESS
Pair a phone for predefined actions over a trusted LAN, Tailscale, a private GitHub relay, or an SMB delivery folder. Remote access is off by default, token protected, and includes explicit warnings for public networking.

LOCAL AND TRANSPARENT
BuildBuddy has no user account, advertising, tracking, or developer-operated data service. Your repositories stay on your Mac unless a command sends them to a provider you configured.

BuildBuddy is a powerful developer utility. Commands can modify files, Git history, remote repositories, deployments, and build artifacts. Review actions and maintain backups.

## Distribution note

The current feature set launches command-line tools, accesses user-selected repositories, manages Git credentials through external tools, and can supervise a local Python helper. Confirm Mac App Store sandbox, hardened runtime, executable-code, and review-policy compatibility before submitting. Direct notarized distribution may be more appropriate without architectural changes.
